// Project 01AI developer tools

AI Code Editor

A browser code editor that maps how a project's files, functions, API routes and data models connect, and uses that map to give safer AI suggestions.

  • Code map: Babel static analysis links imports, calls, Express routes and Mongoose models, and matches frontend requests to backend routes.
  • Goal-based suggestions: readability, performance, security or bug fixes, reviewed in a diff first.
  • Checks on AI output: rejects code that doesn't parse and flags removed exports other files still use.
  • Architecture memory: recorded decisions go with every suggestion, and the model reports whether it followed them.
